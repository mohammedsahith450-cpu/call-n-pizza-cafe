## 🚀 Key Features

1. **Interactive Menu & Sizing**:
   - Small / Medium / Large size toggles for Pizzas with dynamic price recalculation.
   - Category filtering across all items (Pizza, Burgers, Fried Chicken, Chicken Specials, Shawarma/Sandwiches, Momos, Mojitos/Juices, Milkshakes, Fries).
   - Items with unconfirmed prices are safely hidden until updated.

2. **Order via WhatsApp**:
   - Real-time cart drawer calculating order totals.
   - 1-click **Order on WhatsApp** generating an itemized summary directly sent to `+919944399984`.

3. **Food Gallery**:
   - Filterable high-resolution food showcases with Lightbox modal view.

4. **Contact & Social Hub**:
   - Instant "Call Now" buttons (`tel:+919944399984`).
   - "WhatsApp Order" buttons (`https://wa.me/919944399984`).
   - Direct links to official Instagram & YouTube accounts.
